MJTutor は、雀魂の四人南風戦に対応した Codex 向けのローカル麻雀牌譜コーチ・
プラグインです。Mortal の行動評価、牌譜上の公開情報、訂正可能な長期的な
プレイヤー像を組み合わせ、一度きりの解析を継続して質問できる指導対話にします。

MJTutor は、牌譜上の事実、Mortal の出力、ルールに基づく推論、コーチとしての
仮説を区別します。Mortal と異なる選択をすべてミスと判定することもありません。

[更新履歴を見る](CHANGELOG.md)

## 機能

- Codex の会話で雀魂の四人南風戦を直接レビューできます。
- Mortal をローカルで実行せず、Mortal Web でリモート解析できます。
- 既定の Mortal 解析モデルを選択して、次回以降のレビューに利用できます。
- 決定論的な牌姿計算でシャンテン数、有効牌、未見枚数、テンパイまでの手順を
  算出し、Mortal の候補行動や Q 値とは分けて説明します。
- 点数、河、副露、見えている牌から重要な判断を説明します。
- 明示的なフィードバックと複数対局で繰り返す傾向を、確認・訂正・忘却できる
  長期的なプレイヤー像として整理します。
- 対局一覧でローカルレビューを閲覧・絞り込みできます。個人用の牌譜屋 API Key
  があれば、公開対局を同期してレビューする対局を選ぶこともできます。

## インストール

必要なもの：

- macOS または Linux。
- [Codex デスクトップ版](https://developers.openai.com/codex/app) または Codex CLI。
- [`uv`](https://docs.astral.sh/uv/getting-started/installation/)。

### Codex デスクトップ版

**Plugins -> Add from GitHub** で次を入力します。

```text
ukicey/MJTutor
```

一覧から **MJTutor** をインストールし、新しいタスクを作成してプラグインを
読み込ませます。

### Codex CLI

```bash
codex plugin marketplace add ukicey/MJTutor --ref main
codex plugin add mjtutor@mjtutor
```

インストール後、新しい Codex タスクを作成してください。最初に次のように
依頼できます。

```text
MJTutor の設定と既存のプレイヤー像を表示してください。
```

## 牌譜をレビューする

雀魂の牌譜 URL を Codex に直接送ります。例：

```text
MJTutor でこの雀魂の四人南風戦をレビューし、まず学習価値の高い3つの判断を選んでください：
https://game.maj-soul.com/1/?paipu=...
```

初回レビュー時に既定の解析モデルが未設定の場合、MJTutor が利用可能なモデルを
簡潔に紹介し、選択を手伝います。既定値は後から変更でき、対局ごとに別のモデルを
一時的に使うこともできます。

MJTutor は牌譜 URL を入力済みの Mortal Web ページを開き、設定したモデルを
選択します。Cloudflare Turnstile が自動的に完了した場合は、そのまま送信して
レポートを待ちます。操作が必要な場合のみ、自分で認証を完了してください。
生成されたレポートは MJTutor が取り込んでレビューを始めます。認証を回避したり、
ユーザーに代わって完了したりすることはありません。

## 対局一覧

Codex に次のように依頼できます。

```text
MJTutor の対局一覧を開いてください。
```

対局一覧は、取り込み済みでローカルに保存されたレビューを閲覧するための画面です。
アカウント、順位、日付、レビュー状態で絞り込み、対局を選んで牌姿やレビューを
再表示できます。ローカル一覧の利用にアカウントの紐付けは必要なく、雀魂の牌譜
URL を直接レビューする機能にも影響しません。

牌譜屋の公開対局も同期したい場合は、雀魂アカウントを紐付けられます。MJTutor は、
雀魂のプロフィールに表示される UID とニックネームでアカウントを識別します。
初めて牌譜屋と関連付けるときは、そのアカウントのものだと確認した牌譜 URL も1件
必要です。そこから牌譜屋独自の内部アカウント ID を取得するため、通常の利用で
その番号を調べたり覚えたりする必要はありません。牌譜屋のデータには遅延や欠落が
ある場合があります。

同期機能には、サイト管理者が発行した個人用 API Key を各自で取得し、ローカルの
`MJTUTOR_KOROMO_TOKEN` に設定する必要があります。MJTutor はクラウドサービスを
運用せず、開発者の Key を組み込んだり、共有したり、転送したりしません。Key を
チャットや Issue に貼り付けたり、GitHub にコミットしたりしないでください。
Key が未設定の場合、一覧はローカルレビューのみを表示し、牌譜屋への同期リクエスト
は送信しません。

## 長期記憶

レビュー、フィードバック、長期的なプレイヤー像は、既定で次の場所に保存されます。

```text
~/.local/share/mjtutor/coach.sqlite3
```

`XDG_DATA_HOME` が設定されている場合は
`$XDG_DATA_HOME/mjtutor/coach.sqlite3` に保存されます。`MJTUTOR_DATA_DIR` で
別のディレクトリを指定することもできます。

プレイヤー像の情報は、次の 3 種類に分けて扱います。

1. **客観的な観察：** 実際の行動、Mortal の推奨、判断時の局面を示す根拠。
2. **暫定的なプレイヤー像：** 複数対局から見つかった、まだ確認が必要な傾向。
3. **確定したプレイヤー像：** ユーザーが明示的に確認または訂正した打ち方、
   目標、弱点、長所、指導上の好み。

一局全体を振り返る際、コーチは今回の判断を過去の対局と必要な範囲で比較し、
打ち筋や弱点の可能性と反例を能動的に検討します。新しい対局横断の傾向が見えた
とき、従来の見立てが大きく変わったとき、または現在の説明に直接役立つときだけ
自然に触れ、回答のたびに同じプレイヤー像を繰り返すことはありません。

データベースはプラグインのインストール先とは別に保存されるため、更新や
再インストールによって上書きされません。

## 更新

バージョンごとの変更点は[更新履歴](CHANGELOG.md)を参照してください。CLI では
次のコマンドで更新できます。

```bash
codex plugin marketplace upgrade mjtutor
codex plugin add mjtutor@mjtutor
```

更新後は、新しいタスクを作成して新版のプラグインを読み込ませます。
デスクトップ版のプラグイン画面に更新ボタンが表示される場合は、そこから更新
することもできます。

## フィードバック

不具合の報告、機能の提案、指導内容やプレイヤー像への意見は、
[GitHub Issues](https://github.com/ukicey/MJTutor/issues/new/choose) へ送ってください。
不具合報告、機能提案、指導フィードバックのテンプレートを用意しています。

Issue は公開されます。`coach.sqlite3`、アクセスキー、公開したくない牌譜や
個人情報をアップロードしないでください。ログやスクリーンショットからも、
機密情報を取り除いてください。

## データとプライバシー

ローカルデータベースには、雀魂アカウントとニックネーム、Mortal レポート、
牌譜レビュー、指導メモ、プレイヤー像の根拠が含まれる場合があります。これらは
GitHub リポジトリやプラグインパッケージには含まれず、MJTutor がデータベースや
プレイヤー像を自動的にアップロードすることもありません。

雀魂の牌譜 URL は、Mortal Web での解析を選んだ場合にのみ同サービスへ送信
されます。対局同期も、第三者の公開データサービスである牌譜屋に依存します。
